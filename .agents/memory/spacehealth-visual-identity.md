---
name: SpaceHealth visual identity
description: User-stated visual rules for the SpaceHealth dashboard.
---

SpaceHealth uses an immersive charcoal/near-black mission-control base with high-contrast neon cyan and lilac accents. Keep warm beige for readable text and use a restrained coral accent only for critical warning states. Use square corners throughout and put Arabic Typesetting first in the font stack, with Arabic-capable system fallbacks. Prefer larger, readable text over dense layouts, especially for alerts and wrist screens. Preserve Space and Sky as distinct dark themes, with understated astronomical details.

**Why:** The user most recently asked for a deep charcoal/black space theme with glowing neon accents for the hackathon dashboard.

**How to apply:** Use charcoal/black backgrounds, cyan/lilac glow, and restrained coral for critical warnings. Keep alert meaning clear through labels and icons as well as color, and let text wrap on narrow displays rather than shrinking it.
