---
name: SpaceHealth visual identity
description: User-stated visual rules for the SpaceHealth dashboard.
---

SpaceHealth uses a light, space-inspired interface with lavender/purple, light sky blue, soft beige, and white as its only main color families. Use square corners throughout and put Arabic Typesetting first in the font stack, with Arabic-capable system fallbacks. Preserve the Space and Sky choices as light themes, subtle astronomical details, and clear wrist-sized layouts.

**Why:** The user specified these as standing product requirements for the astronaut health dashboard.

**How to apply:** Follow these constraints when updating any SpaceHealth screen or shared styling. Keep anomaly meaning clear through labels and icons as well as color, and use darker tonal shades of the four families only when needed for readable text.
