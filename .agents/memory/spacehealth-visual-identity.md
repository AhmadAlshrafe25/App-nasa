---
name: SpaceHealth visual identity
description: User-stated visual rules for the SpaceHealth dashboard.
---

SpaceHealth uses a dark mission-control interface with Deep Space Navy (#10152B), Cosmic Purple (#8B72D6), Astronaut Sky Blue (#8CCFFF), and Moon Beige (#E8DCC8) as its only color families. Use square corners throughout and put Arabic Typesetting first in the font stack, with Arabic-capable system fallbacks. Prefer larger, readable text over dense layouts, especially for alerts and wrist screens. Preserve Space and Sky as distinct dark themes, with understated astronomical details.

**Why:** The user’s updated dashboard brief replaced the earlier light palette with a dark NASA-inspired mission console and asked for larger text to improve readability.

**How to apply:** Follow these constraints on every SpaceHealth screen. Keep anomaly meaning clear through labels and icons as well as color, use only tints of the four specified families, and let text wrap on narrow displays rather than shrinking it.
