Use short labels and action-first messages throughout SpaceHealth. Remove repeated explanations and implementation language from the main screens; place useful technical detail in optional expandable sections.

**Why:** The user repeatedly asked to remove extra talk and technical clutter so astronauts can use the app easily, then extended that request to the entire app.

**How to apply:** Keep readings, actions, recording controls, and error recovery obvious. Do not remove features or their behavior merely to shorten the page. Retain a clear demo/no-live-sensors label, necessary medical and storage warnings, real-versus-sample media distinctions, and required model license credits.
